# 🎵 SuperMusic

Welcome to the **SuperMusic** project — a Python-based pipeline for downloading, processing, enriching, and visualizing music metadata. This repository powers automated downloads, stem separation, transcription to MIDI, metadata enrichment, and interactive web visualizations.

---

## 🚀 Features
- **Audio Downloads** from YouTube or other sources
- **Stem Separation** for vocals, drums, bass, etc.
- **Transcription** to MIDI or note events
- **Metadata Enrichment** with external APIs & datasets
- **3D Visualizations** (UMAP, Plotly) for music similarity
- **Interactive Web App** built with FastAPI/Flask + Jinja2
